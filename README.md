# LeviLauncher Download

Download all three parts from https://github.com/mkuko52/LeviLauncher-download/releases/latest into the same folder.

Windows Command Prompt:
```bat
copy /b LeviLauncher.tar.gz.part001+LeviLauncher.tar.gz.part002+LeviLauncher.tar.gz.part003 LeviLauncher.tar.gz
```

Linux/macOS:
```sh
cat LeviLauncher.tar.gz.part001 LeviLauncher.tar.gz.part002 LeviLauncher.tar.gz.part003 > LeviLauncher.tar.gz
```

Verify the SHA-256 against SHA256.txt, then extract LeviLauncher.tar.gz.
